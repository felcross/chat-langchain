# Quick Fixes Round 2 — FinanceBot BR (2 mudanças)

## 1. SQL LIMIT safety net
- **Arquivo:** `db_manager.py:150-152`
- **Mudança:** Após `df = con.execute(sql).df()`, adicionar `if len(df) > 100: df = df.head(100)`
- **Porquê:** Previne RAM alta se LLM gerar query sem LIMIT

## 2. Retry na API BCB
- **Arquivo:** `etl_bcb.py:67`
- **Mudança:** Envolver `requests.get()` em loop de 3 tentativas com backoff exponencial (1s, 2s, 4s)
- **Porquê:** API BCB é instável, sem retry o ETL falha inteiro

## Verificação
- SQL LIMIT: executar query longa e verificar que retorna no máximo 100 linhas
